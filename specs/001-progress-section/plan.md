# Implementation Plan: Progress Section

**Branch**: `001-progress-section` | **Date**: 2026-06-28 | **Spec**: [spec.md](spec.md)

## Summary

Add a family progress dashboard that shows this week's activity ring, a running streak counter with automatic Sunday-evening freeze protection, and all-time totals. A glanceable version surfaces on the home screen. The weekly goal is set during onboarding. Streak state is maintained on the `families` table and updated at completion time; a background job handles Sunday-evening auto-freezes.

---

## Technical Context

**Language/Version**: Python 3.12 (server), TypeScript 5.x / React Native / Expo 54 (client)

**Primary Dependencies**: FastAPI, SQLAlchemy 2.x async, asyncpg (server) · Expo Router, react-native-svg, react-i18next (client)

**Storage**: PostgreSQL 16 — new columns on `families` table; stats computed at query time from `completions`

**Testing**: pytest (server) · Jest / React Native Testing Library (client)

**Target Platform**: iOS 15+ / Android (Expo managed workflow)

**Project Type**: Mobile app + REST API backend

**Performance Goals**: Progress endpoint responds in < 500 ms; home-screen widget loads in same request as challenges (no extra round-trip if co-located)

**Constraints**: Spec-driven — `docs/openapi.yaml` updated before any route implementation; streak logic must be race-condition safe; no cross-family data exposed

**Scale/Scope**: One progress record per family; stats aggregated from existing `completions` table
